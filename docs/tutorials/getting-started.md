# 튜토리얼: 처음부터 VPN 연결까지

이 튜토리얼을 끝까지 따라 하면, 맥북 메뉴바에서 클릭 한 번으로 회사 FortiClient SSL-VPN에 연결되는 상태까지 만들 수 있습니다. 옵션이나 대안은 다루지 않습니다 — 가장 표준적인 경로만 순서대로 따라가면 됩니다.

## 준비물

- macOS를 쓰는 맥북
- 회사에서 받은 VPN 계정(아이디/비밀번호)
- 다음(Daum) 또는 카카오 메일 계정 — 인증 메일(OTP)이 여기로 옵니다

## 1단계. 메일에서 IMAP 켜기

이 앱은 인증 메일을 직접 읽어서 OTP를 자동으로 입력해 줍니다. 그러려면 메일함에서 IMAP 접근을 허용해야 합니다.

1. [Daum 메일](https://mail.daum.net)에 로그인하고, 좌측 하단 **환경설정**을 클릭합니다.
2. 상단 메뉴에서 **IMAP/POP3** 탭을 선택합니다.
3. **IMAP/SMTP 서비스**를 **사용함**으로 바꾸고 저장합니다.

카카오 메일이나 2단계 인증을 쓰는 다음 계정이라면, 평소 로그인 비밀번호가 아니라 **앱 비밀번호**가 따로 필요합니다. 카카오 계정 관리 페이지의 **보안 → 2단계 인증 → 앱 비밀번호**에서 하나 만들어 두세요. 이 앱 비밀번호를 3단계에서 메일 비밀번호로 씁니다.

## 2단계. 설치 스크립트 실행

터미널을 열고 이 저장소 폴더로 이동한 뒤 실행합니다.

```bash
chmod +x setup.sh
./setup.sh
```

`openfortivpn`, Python 패키지, 그리고 매번 sudo 비밀번호를 묻지 않도록 하는 권한 설정을 한 번에 처리합니다. 중간에 맥북 로그인 비밀번호를 한 번 물어봅니다 — 정상입니다.

## 3단계. 앱 실행하기

```bash
./run.sh
```

화면 우측 상단 메뉴바에 🔴 아이콘이 새로 생기면 성공입니다.

## 4단계. 최초 설정 등록

🔴 아이콘을 클릭하고 **Settings**를 선택하면 브라우저가 열립니다. 아래 값을 채워 넣으세요.

| 필드          | 채울 값                                              |
| ------------- | ----------------------------------------------------- |
| VPN Host      | 회사 VPN 서버 주소 (예: `vpn.daily-funding.com`)      |
| VPN Port      | 보통 `443`                                            |
| VPN Username  | 본인 VPN 아이디                                       |
| VPN Password  | 본인 VPN 비밀번호                                     |
| IMAP Host     | 다음 메일은 `imap.daum.net`, 카카오 메일은 `imap.kakao.com` |
| IMAP Port     | `993`                                                 |
| Mail ID       | 본인 메일 전체 주소 (예: `honggildong@daum.net`)      |
| Mail Password | 메일 비밀번호 (2단계 인증자는 1단계에서 만든 앱 비밀번호) |

저장하면 끝입니다. 비밀번호 두 개(VPN, 메일)는 화면이나 파일 어디에도 평문으로 남지 않고 macOS Keychain에만 저장됩니다.

## 5단계. 처음 연결해 보기

1. 🔴 아이콘을 클릭하고 **Connect VPN**을 선택합니다.
2. Touch ID(지문 인식) 창이 뜹니다. 지문을 대거나 맥 비밀번호를 입력합니다.
3. 아이콘이 🟡로 바뀝니다 — 터널을 연결하고 인증 메일의 OTP를 자동으로 기다리는 중입니다.
4. 잠시 뒤 아이콘이 🟢로 바뀌고 macOS 알림이 뜨면, VPN이 정상적으로 연결된 것입니다.

여기까지 오셨다면 완료입니다. 다음에 다시 연결할 때는 3~4단계를 반복할 필요 없이 곧바로 5단계만 하면 됩니다.
