# FortiAutoConn 문서

이 문서는 [Diátaxis](https://diataxis.fr) 체계에 따라 목적별로 네 종류로 나뉘어 있습니다. 지금 필요한 게 무엇인지에 따라 골라 보세요.

|                                | 이런 게 궁금할 때                          | 문서                                                       |
| ------------------------------ | ------------------------------------------ | ---------------------------------------------------------- |
| 🎓 **튜토리얼** (학습)          | "처음 써보는데 어떻게 시작하죠?"           | [처음부터 VPN 연결까지](tutorials/getting-started.md)      |
| 🔧 **How-to 가이드** (작업)     | "OO를 하고 싶은데 어떻게 하나요?"          | [로그인 시 자동 실행 등록](how-to-guides/enable-autostart.md), [스플릿 터널링 설정](how-to-guides/configure-split-tunnel.md), [자꾸 끊기는 연결 진단하기](how-to-guides/diagnose-frequent-disconnects.md) |
| 📖 **레퍼런스** (조회)          | "그 설정 필드 이름이 정확히 뭐였지?"       | [설정 필드](reference/configuration.md), [명령어/스크립트](reference/commands.md) |
| 💡 **설명** (이해)              | "왜 이렇게 만들었지? 원리가 뭐지?"         | [아키텍처와 설계 결정](explanation/architecture.md)         |

- **튜토리얼**은 손을 잡고 처음부터 끝까지 안내합니다. 순서대로 따라 하면 됩니다.
- **How-to 가이드**는 이미 기본적으로 쓸 줄 아는 사람이 특정 목적을 달성하기 위한 지침입니다.
- **레퍼런스**는 정확한 사실(필드명, 기본값, 경로, 명령어)을 찾아보는 용도입니다. 설명이 아니라 목록입니다.
- **설명**은 "어떻게"가 아니라 "왜"를 다룹니다. 배경, 트레이드오프, 설계 이유를 담습니다.

AI 코딩 에이전트(Claude Code 등)를 위한 코드베이스 가이드는 별도로 저장소 루트의 [`CLAUDE.md`](../CLAUDE.md)에 있습니다. 사람이 읽는 이 문서들과는 독자와 목적이 다릅니다.
